개인정보 동의서 점검

Windows
1. ZIP을 모두 압축 해제합니다.
2. Python 3이 설치된 상태에서 start-windows.bat을 더블 클릭합니다.
3. GPT 방식에 사용할 OpenAI API 키를 실행 창에 입력합니다.
   키 입력 문자는 화면에 표시되지 않습니다. Enter를 누르면 입력이 완료됩니다.
4. 자동으로 열린 브라우저에서 두 방식을 각각 실행한 뒤 결과 탭으로 비교합니다.
   자동으로 열리지 않으면 실행 창의 주소를 브라우저에 붙여 넣습니다.

macOS / Linux
폴더에서 터미널을 열고 python3 run_review.py를 실행합니다.

기존 방식만 사용할 때는 consent-review.html을 바로 열면 됩니다.
GPT 방식 실행 시 원문이 OpenAI API로 전송되며 API 이용료가 발생할 수 있습니다.
API 키는 실행 중 로컬 프로그램의 메모리에만 보관됩니다.
API 키 발급: https://platform.openai.com/api-keys
