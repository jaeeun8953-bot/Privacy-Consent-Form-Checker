기존 GitHub 저장소 Privacy-Consent-Form-Checker에서 적용하기

1. ZIP 압축을 풉니다.
2. GitHub 저장소의 Add file → Upload files에서 app.py, original_samples_2000.csv, original_corpus_hash.txt 세 파일을 올립니다.
3. Commit changes로 저장합니다. 기존 model_study.py, run_review.py, requirements.txt는 유지합니다.
4. Streamlit 앱을 새로고침합니다. 제목이 ‘동일한 2,000문장에서 세 방식 비교’로 바뀌면 적용 완료입니다.
5. 기본 데이터는 안전 1,000개·위험 1,000개입니다. 별도 업로드 없이 ‘다음 20문장 평가’로 시작합니다.
6. 실행 후 문장별 결과 CSV를 내려받습니다. 세션이 종료되면 이 CSV를 불러와 이어갑니다.
7. 전체 2,000문장이 완료되면 기존 유사도 68.78%, GPT-3 76.05%와 이번 GPT-5 정확도 비교 그래프 및 비교 CSV가 표시됩니다.

API 키는 기존 Streamlit Secrets를 사용합니다. 실행 시 API 이용료가 발생합니다.
처리 시간은 문장별 API 왕복 시간입니다. 과거 모델과 동일한 환경·프롬프트를 재현한 실험으로 설명하지 않습니다.
GPT-5 평가는 아직 실행하지 않았습니다. 예시 결과나 가짜 성능값은 포함하지 않았습니다.

추가 기능: 정확도와 함께 세 방식의 문장당 평균 처리 시간 비교(로그 축), GPT-5 평가 진행 중 누적 평균 처리 시간 그래프를 표시합니다. 비교 CSV에도 속도를 포함합니다.
이미 이전 수정본을 적용했다면 app.py만 교체하면 됩니다.
